# Bubble Blush — Brand basics

`logo.png`: the original logo (2000×2000). The POS uses cropped and black-and-white copies in `pos/assets/`.

## Colours (from the logo)

| Name | Hex | Use |
|---|---|---|
| Dusty teal | `#A8C3C9` | Logo "B" outline, light accents |
| Deep teal | `#4E7F87` | Buttons, headings, prices |
| Boba teal | `#6F9FA6` | Bubbles, highlights |
| Mist | `#EFF9FC` | Backgrounds |
| Sage | `#8DA196` | Wordmark "BUBBLE BLUSH" |
| Gold | `#C9A24A` | Small accents (straw ring), "signature" items |
| Blush | `#F2C4C0` | Optional warm accent for promos |

## Tone & naming

Soft, friendly, and local. Drink names mix the brand ("Blush"), dreamy words ("Cloud", "Mist", "Sunset"), and Khulna pride (*Rupsha Mango Breeze*, *Sundarban Honey Lemon*, *Khejur Gur Boba*). In winter, push the khejur gur (date-palm jaggery) specials.
